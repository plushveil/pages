What is Context Injection?

Context injection allows you to pass dynamic configuration to your JavaScript bundles at runtime via query parameters (serve mode) or at build time (build mode).

This page demonstrates the feature by loading context-demo.js?ctx=demowhich injects a context object into the bundle.

⚠️ Security Warning

Context objects are embedded in your JavaScript bundle.Never include sensitive data like real API keys, secrets, or private tokens in context objects.Anything in the context is visible to anyone who can view your JavaScript source. Use context for public configuration only (API endpoints, feature flags, public IDs).

Configuration

In pages.config.mjs:

export const js = {
  // For serve: contexts resolved from ?ctx=X
  // For build: generate separate files
  buildContexts: ['demo', 'production'],

  contextResolve: (ctxName) => {
    if (ctxName === 'demo') {
      return {
        publicApiUrl: 'https://demo.api.example.com',
        publicApiKey: 'demo_key_12345',
        features: { darkMode: true, analytics: false }
      }
    }
    if (ctxName === 'production') {
      return {
        publicApiUrl: 'https://api.example.com',
        publicApiKey: 'prod_key_67890',
        features: { darkMode: true, analytics: true }
      }
    }
  }
}

Usage in JavaScript

Import the ctxobject from page:ctxto access context:

// Import ctx from the virtual module
import ctx from 'page:ctx'

console.log('API URL:', ctx.publicApiUrl)
console.log('API Key:', ctx.publicApiKey)
console.log('Features:', ctx.features)

// Use it in your app
if (ctx.features.darkMode) {
  document.body.classList.add('dark-mode')
}

Tree-Shaking with Context

Context properties in conditions enable dead code elimination:

import ctx from 'page:ctx'

// Analytics only loaded in production
if (ctx.name !== 'production') import('./analytics.js')

// Context properties are inlined at build time
if (ctx.features.analytics) {
  trackPageView()
}

// When ctx.name === 'demo', the import and analytics code
// are completely removed from the bundle via tree-shaking

Loading Different Contexts

Serve Mode (Dynamic):

<script src="./script.js?ctx=demo"></script>

Context resolved at request time

Build Mode (Static):

Generates: script.js, script-ctxdemo.js, script-ctxproduction.js

Each file has its context baked in

💡 Use Cases

  • Different API endpoints for dev/staging/production
  • Feature flags without runtime overhead
  • API keys and configuration per environment
  • A/B testing variants
  • Locale-specific configuration
